Internship (student/recent grad): Emphasize coursework + projects + readiness. Frame Yoonee AI as "already did an internship and shipped real features." Use "hit the ground running" energy.

Entry-Level / Early Career (0-3 years exp): Emphasize shipped work + autonomy. Experience above education. Frame Revature as leadership, Yoonee as production AI work. "I've already built X, ready to build Y at scale."

Mid-Level (stretch, rare): Same as entry-level but lean harder into Revature program ownership + Yoonee shipped features. Be honest this is a stretch.
