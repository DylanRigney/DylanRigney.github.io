# Dylan Rigney — Software Developer Portfolio

Personal portfolio web application showcasing projects, technical background, and interactive AI advocate experience.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 18, TypeScript)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), Framer Motion, Lucide Icons
- **AI Integration:** Interactive career advocate backed by OpenAI / DeepSeek API endpoints
- **Deployment:** [Vercel](https://dylanrigney.vercel.app/)

## Getting Started

Run the development server locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Build & Test

```bash
# Production build
npm run build

# Linting
npm run lint
```
